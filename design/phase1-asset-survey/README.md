# เฟส 1 — แบบสำรวจครุภัณฑ์ (งานพัสดุ)

เอกสารออกแบบ (design canvas) สำหรับเฟสแรกของ **ระบบบริหารงบประมาณโรงเรียน**
คือให้ **ครูประจำห้อง** เป็นผู้สำรวจและบันทึกครุภัณฑ์ในห้องของตัวเอง
เพื่อสร้างทะเบียนครุภัณฑ์ตั้งต้นทั้งโรงเรียน

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | คำอธิบาย |
| --- | --- |
| `สำรวจครุภัณฑ์ v1.dc.html` | เวอร์ชันล่าสุด — แผนผังภาพรวม 4 งาน + ฟอร์ม 3 แนวทาง (มีปุ่มกดใช้งานได้จริงในหน้า) |
| `ระบบสำรวจครุภัณฑ์.dc.html` | เวอร์ชันแรก — โครงสร้างฟอร์ม 3 แบบ + แผนผังระบบและบทบาทผู้ใช้ |
| `support.js` | สคริปต์ประกอบการเรนเดอร์ของไฟล์ `.dc.html` (ต้องอยู่โฟลเดอร์เดียวกัน) |
| `thumbnail.webp` | ภาพตัวอย่างหน้าปก |

เปิดดูโดยเปิดไฟล์ `.dc.html` ในเบราว์เซอร์ (ต้องมี `support.js` อยู่ข้าง ๆ)

## ขอบเขตเฟส 1

- ผู้ใช้หลัก = **ครู** (ไม่ใช่เจ้าหน้าที่พัสดุ) กรอกประมาณ 10–50 รายการ/คน
- กรอกจาก **มือถือ** ในห้องเป็นหลัก แต่ต้องใช้บนคอมพิวเตอร์ได้ด้วย
- หมายเลขครุภัณฑ์ **พิมพ์เอง** (ยังไม่มี QR) → ต้องมี keypad และตรวจเลขซ้ำ
- ผลลัพธ์: รายการครุภัณฑ์รายห้อง พร้อมรูปและสภาพ ส่งออกเป็นบัญชีครุภัณฑ์ประจำปีได้

### ฟิลด์ข้อมูล

อาคาร · ชั้น · เลขห้อง · หมวดหมู่ · ชื่อครุภัณฑ์ · จำนวน · หน่วย ·
หมายเลขครุภัณฑ์ · สภาพ · ปีที่ได้มา · แหล่งงบ · ราคา · รูปถ่าย 1 รูป · หมายเหตุ

ฟิลด์บังคับมีแค่ 5 อย่าง (ห้อง · ชื่อครุภัณฑ์ · จำนวน · สภาพ · รูป)
ที่เหลือพับเก็บใต้ "ข้อมูลเพิ่มเติม" เพื่อลดภาระของครู

### สภาพการใช้งาน

`ใช้งานได้` · `ชำรุด` (พัสดุตามซ่อม) · `รอจำหน่าย` (ซ่อมไม่คุ้ม เสนอจำหน่าย)

## 3 แนวทางของฟอร์ม (จาก v1)

| แนวทาง | อุปกรณ์ | จุดเด่น |
| --- | --- | --- |
| **1b** ทีละขั้น + ถ่ายรูปนำ | มือถือ | เปิดกล้องก่อนแล้วค่อยกรอก ทีละคำถามชุดเล็ก ปลอดภัยที่สุดกับครูที่ไม่ถนัดเทค |
| **1c** หน้าเดียว เลื่อนกรอกรวด | มือถือ | เห็นทุกช่องพร้อมกัน ไม่มีขั้นตอนให้จำ เหมาะกับคนที่จดข้อมูลมาแล้ว |
| **1d** โหมดกรอกเร็ว | คอมพิวเตอร์ | ล็อกห้องไว้ที่หัวจอ กรอกทีละแถว `Enter` = แถวใหม่ · `⌘D` = ทำซ้ำแถวบน · ลากรูปหลายไฟล์มาจับคู่ตามลำดับแถว |

กลไกช่วยกรอกซ้ำที่ปรากฏในทุกแนวทาง: จำอาคาร/ชั้น/ห้องล่าสุด, คัดลอกจากแถวล่าสุด,
บันทึกแล้วเพิ่มรายการถัดไปในห้องเดิมทันที

## แผนผังภาพรวม — เฟส 1 อยู่ตรงไหน

แกนกลางคือ "งบประมาณหนึ่งก้อน" ที่ไหลผ่านทั้ง 4 งาน

| งาน | ขอบเขต | เฟส |
| --- | --- | --- |
| 01 งานแผนงาน | ตั้งแผนปฏิบัติการ · จัดสรรงบตามโครงการ · อนุมัติคำขอซื้อ | เฟส 3 |
| 02 งานพัสดุ | จัดซื้อจัดจ้าง · ทะเบียนครุภัณฑ์ · ตรวจสอบประจำปี · จำหน่ายพัสดุ | **เฟส 1** |
| 03 งานการเงิน | เบิกจ่าย · ใบสำคัญ · ยืมเงินราชการ · คุมเงินคงเหลือรายหมวด | เฟส 2 |
| 04 งานบัญชี | ลงบัญชีสินทรัพย์ · ค่าเสื่อมราคา · งบการเงิน · รายงานต้นสังกัด | เฟส 4 |

เริ่มที่การสำรวจ เพราะทะเบียนครุภัณฑ์ที่ตรงกับของจริงเป็นฐานของอีก 3 งาน
ถ้าข้อมูลนี้ผิด ค่าเสื่อมราคาและแผนซื้อทดแทนก็ผิดทั้งหมด

### บทบาทผู้ใช้

- **ครูประจำห้อง** — กรอกแบบสำรวจ ถ่ายรูป แจ้งชำรุด
- **เจ้าหน้าที่พัสดุ** — ตรวจสอบ อนุมัติ ออกเลขครุภัณฑ์ ทำรายงาน
- **หัวหน้ากลุ่มสาระ** — ดูความคืบหน้าห้องในความดูแล
- **ผู้บริหาร** — ภาพรวมมูลค่าสินทรัพย์ · ครุภัณฑ์ชำรุดรอจำหน่าย

## คำถามที่ยังต้องการคำตอบก่อนลงมือพัฒนา

1. รายชื่อครุภัณฑ์มีบัญชีมาตรฐานให้เลือกไหม หรือให้ครูพิมพ์อิสระ
2. รูปแบบหมายเลขครุภัณฑ์จริงของโรงเรียน (ตัวอย่างในแบบใช้ `7440-001-0012/2566`)
3. ผังอาคาร–ห้องจริง เพื่อทำ dropdown ให้ตรงกับของโรงเรียน
4. กรณี "ยังไม่ติดป้าย" — พัสดุออกเลขให้ทีหลังด้วยกระบวนการใด
